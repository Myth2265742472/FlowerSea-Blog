# 双ESP32云台系统接线说明

## 系统组成

本系统由两个独立的ESP32设备组成：
1. **发送端（Transmitter）**：ESP32-S3 + MPU6050
2. **接收端（Receiver）**：ESP32 + 两个舵机

---

## 发送端接线（MPU6050 + ESP32-S3）

### 引脚连接图

```
MPU6050 模块
┌──────────────┐
│  VCC  → 3.3V │
│  GND  → GND  │
│  SCL  → GPIO18
│  SDA  → GPIO17
└──────────────┘


ESP32-S3 开发板（发送端）
┌─────────────────────────────────┐
│                                 │
│  GPIO17  ────────── SDA         │
│  GPIO18  ────────── SCL         │
│  3.3V    ────────── MPU6050 VCC │
│  GND     ────────── MPU6050 GND │
│  USB     ────────── 电脑供电     │
│                                 │
└─────────────────────────────────┘
```

### 详细连接表

| MPU6050 | ESP32-S3 | 颜色 | 说明 |
|---------|----------|------|------|
| VCC | 3.3V | 红色 | 电源正极（必须3.3V！） |
| GND | GND | 黑色 | 地线 |
| SCL | GPIO 18 | 黄色 | I2C时钟线 |
| SDA | GPIO 17 | 蓝色 | I2C数据线 |

### 重要注意事项

1. **电压**：MPU6050必须使用3.3V供电，接5V会烧坏芯片
2. **I2C引脚**：代码中配置的是GPIO17和GPIO18，请确保正确连接
3. **方向**：SDA和SCL不要接反

## 接收端接线（舵机 + ESP32）

### 引脚连接图

```
舵机1（俯仰）
┌───────────┐
│  红线 → 5V电源       （电源正极）
│  棕线 → GND         （地线）
│  橙线 → GPIO12       （信号线）
└───────────┘


舵机2（平面转角）
┌───────────┐
│  红线 → 5V电源       （电源正极）
│  棕线 → GND         （地线）
│  橙线 → GPIO13       （信号线）
└───────────┘


ESP32 开发板（接收端）
┌─────────────────────────────────┐
│                                 │
│  GPIO12  ────────── 俯仰舵机信号│
│  GPIO13  ────────── 平面转角舵机信号│
│  5V      ────────── 可选       │
│  GND     ────────── 公共地     │
│  USB     ────────── 电脑供电     │
│                                 │
└─────────────────────────────────┘
```

### 详细连接表

#### 俯仰舵机 → ESP32（接收端）

| 舵机 | ESP32 | 颜色 | 说明 |
|------|-------|------|------|
| 红线（+） | 5V电源 | 红色 | 电源正极（需独立电源） |
| 棕线/黑线（-） | GND | 黑色 | 地线（共地） |
| 橙线/黄线（信号） | GPIO 12 | 黄色 | 信号线 |

#### 平面转角舵机 → ESP32（接收端）

| 舵机 | ESP32 | 颜色 | 说明 |
|------|-------|------|------|
| 红线（+） | 5V电源 | 红色 | 电源正极（需独立电源） |
| 棕线/黑线（-） | GND | 黑色 | 地线（共地） |
| 橙线/黄线（信号） | GPIO 13 | 黄色 | 信号线 |

## 电源分配

### 推荐供电方案

```
发送端（Transmitter）
USB供电 → ESP32-S3 → MPU6050
       ↓
   电脑


接收端（Receiver）
外部5V电源（2A+）
    ├──→ 舵机1（俯仰）红线
    ├──→ 舵机2（平面转角）红线
    └──→ ESP32 VIN（可选）

公共地线
    ├──→ 舵机1棕线
    ├──→ 舵机2棕线
    └──→ ESP32 GND
```

### 电源要求

**发送端：**
- ESP32-S3：USB供电（500mA）
- MPU6050：3.3V，约5mA
- **总功耗**：约150mA

**接收端：**
- ESP32：USB供电或5V电源，约100mA
- 舵机1：5V，约500-800mA（动作时）
- 舵机2：5V，约500-800mA（动作时）
- **总功耗**：约1-2A（取决于舵机类型）

**重要**：接收端舵机必须使用独立5V电源，不能直接用ESP32的5V引脚供电！

---

## 舵机电源说明

### 为什么需要独立电源？

1. **电流需求大**：两个舵机同时动作时可能需要1.5A以上电流
2. **电压稳定**：舵机动作时会造成电压波动，影响ESP32工作
3. **防止复位**：电压过低会导致ESP32重启

### 电源选择建议

**小功率舵机（如SG90）：**
- 2A USB适配器
- 或 5V 2A稳压模块

**大功率舵机（如MG996R）：**
- 5V 3A以上电源适配器
- 或锂电池（2S，7.4V，配合5V稳压模块）

### 电源连接示例

```
5V电源适配器（3A）
    ├─[红线]──→ 舵机1 VCC
    ├─[红线]──→ 舵机2 VCC
    └─[黑线]──→ 公共地线（连接到ESP32 GND、舵机1 GND、舵机2 GND）
```

---

## 接地连接（非常重要！）

所有设备的GND必须连接在一起（共地），这是系统稳定工作的关键。

```
公共地线连接：
┌─────────────────────────────────────────┐
│                                         │
│  发送端GND ─┐                           │
│             ├──→ 公共地 ───→ 接收端GND  │
│  电脑USB地 ─┘         │                  │
│                       ├──→ 舵机1 GND   │
│                       └──→ 舵机2 GND   │
│                                         │
└─────────────────────────────────────────┘
```

**无线系统的特殊情况：**
- 由于两个ESP32是独立的，不需要物理连接地线
- 每个ESP32需要与各自连接的设备共地
- 发送端：ESP32-S3 ↔ MPU6050 共地
- 接收端：ESP32 ↔ 舵机1 ↔ 舵机2 ↔ 电源 共地

## 测试步骤

### 1. 单独测试发送端
- 只连接MPU6050到ESP32-S3
- 上传 `transmitter.ino`
- 查看串口输出，确认MPU6050工作正常
- 记录本机MAC地址
- 等待归零校准完成（约3秒）

### 2. 单独测试接收端
- 只连接舵机到ESP32
- 上传 `receiver.ino`
- 查看串口输出，确认舵机初始化成功
- 记录本机MAC地址

### 3. 配置MAC地址
- 将接收端的MAC地址填入发送端代码中的 `receiverMacAddress`
- 将发送端的MAC地址填入接收端代码中的 `transmitterMacAddress`
- 重新上传两个程序

### 4. 完整系统测试
- 两个设备都上电
- 观察发送端和接收端的串口输出
- 移动发送端的MPU6050
- 观察接收端的舵机是否同步转动

## 常见问题

### Q: 接收端显示"⚠ 接收超时"？
A:
1. 检查MAC地址是否正确配置
2. 检查两个设备是否都上电
3. 检查设备距离（建议10米以内）
4. 重启两个设备重新连接

### Q: 舵机不转动？
A:
1. 检查5V电源是否充足
2. 检查信号线连接
3. 检查引脚配置是否正确（GPIO12和GPIO13）
4. 查看接收端串口输出，确认收到数据

### Q: 发送端MPU6050检测不到？
A:
1. 检查I2C接线（SDA/SCL不要接反）
2. 检查3.3V电源
3. 检查上拉电阻（通常模块自带）
4. 确认使用正确的GPIO引脚（17和18）

### Q: 舵机抖动严重？
A:
1. 检查电源稳定性
2. 增大死区参数 `DEAD_ZONE`（在代码中修改）
3. 增加滤波样本数 `FILTER_SAMPLES`
4. 使用更好的电源

### Q: 角度不准确？
A:
1. 等待发送端的归零校准完成
2. 确保MPU6050水平放置
3. 调整卡尔曼滤波器参数
4. 校准中心位置 `PITCH_CENTER` 和 `YAW_CENTER`

## 代码参数调整

### 发送端参数（transmitter.ino）

```cpp
// 数据发送间隔（毫秒）
const int SEND_INTERVAL = 30;  // 增大可降低频率，减小可提高响应

// 卡尔曼滤波器参数
const float Q_angle = 0.001;   // 角度噪声（越小越信任模型）
const float Q_gyro = 0.003;    // 陀螺仪噪声（越小越信任陀螺仪）
const float R_angle = 0.03;     // 测量噪声（越大越信任预测）
```

### 接收端参数（receiver.ino）

```cpp
// 角度同步比例
const float PITCH_SCALE = 1.0;  // 俯仰角比例（0.5=减半，2.0=加倍）
const float YAW_SCALE = 1.0;    // 平面转角比例（0.5=减半，2.0=加倍）

// 平滑滤波
#define FILTER_SAMPLES 15  // 样本数（越大越平滑，但延迟越大）

// 死区控制
#define DEAD_ZONE 2.0  // 死区角度（度），小于此值不更新舵机
```

## 改进说明

### 相比之前版本的改进：

1. **归零校准**：启动时自动校准偏移量
2. **平滑滤波**：使用移动平均滤波减少舵机抖动
3. **死区控制**：避免小角度变化时的频繁动作
4. **双舵机控制**：支持俯仰和平面转角两个舵机
5. **卡尔曼滤波**：更精确的姿态估计
6. **超时检测**：检测接收端是否断线
7. **PWM定时器优化**：更稳定的舵机控制
