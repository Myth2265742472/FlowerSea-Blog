ESP-NOW版本快速开始指南
=====================

5分钟快速开始:

步骤1: 准备硬件
---------------
ESP32 #1 (发送端):
- 连接MPU6050:
  VCC -> 3.3V
  GND -> GND
  SCL -> GPIO6
  SDA -> GPIO5

ESP32 #2 (接收端):
- 连接SG90舵机:
  红线 -> 5V (外部5V电源)
  棕线 -> GND
  橙线 -> GPIO7

步骤2: 上传接收端程序
--------------------
1. 打开 Servo_ESPNOW_Receiver.ino
2. 选择: ESP32S3 Dev Module
3. 选择正确的COM口
4. 点击上传
5. 打开串口监视器(115200波特率)
6. 记录MAC地址，例如: AA:BB:CC:DD:EE:FF

步骤3: 上传发送端程序
--------------------
1. 打开 MPU6050_ESPNOW_Transmitter.ino
2. 找到这一行:
   uint8_t receiverMAC[] = {0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF};
3. 将MAC地址替换为接收端的MAC地址

示例:
假设接收端MAC是: 7C:9E:BD:4A:12:34
改为:
   uint8_t receiverMAC[] = {0x7C, 0x9E, 0xBD, 0x4A, 0x12, 0x34};

4. 上传到发送端ESP32

步骤4: 测试
----------
1. 观察接收端串口: 应该显示"接收: X=..."
2. 倾斜MPU6050，舵机应该跟随转动
3. 观察发送端串口: 应该显示"发送: X=..."

完成!
------

ESP-NOW优势:
------------
✓ 无需WiFi名称和密码
✓ 无需IP地址配置
✓ 连接更稳定，不会断线
✓ 延迟更低
✓ 使用更简单

与TCP版本对比:
-------------
TCP版本:
- 需要配置WiFi SSID和密码
- 需要配置IP地址
- 可能出现连接断开
- 需要路由器（可选）

ESP-NOW版本:
- 只需要配置MAC地址
- 不会断线
- 不需要路由器
- 更简单稳定

如果舵机仍然卡顿:
-----------------
最可能的原因: 电源供电不足！

解决方案:
1. 使用外部5V电源给舵机供电
2. 或用5V充电宝供电
3. 确保舵机GND与ESP32 GND共地

调整参数（可选）:
----------------
增大死区（更平滑）:
在接收端修改: #define DEAD_ZONE 3.0 或 4.0

降低频率（更稳定）:
在发送端修改: const int updateInterval = 50;

增加滤波（更平滑）:
在接收端修改: #define FILTER_SAMPLES 20
