=====================================
  机械臂视觉检测系统 - 使用说明
=====================================

一、文件说明
-------------------------------------
汇总/
├── video_client_server.py  主程序
├── run.sh                  启动脚本
└── templates/
    └── new_index.html      网页界面

二、使用步骤
-------------------------------------
1. 用WinSCP把"汇总"文件夹上传到树莓派 /home/pi/

2. 打开终端，执行以下命令：

   cd /home/pi/汇总
   chmod +x run.sh
   ./run.sh

3. 打开浏览器访问：
   http://树莓派IP:7788

三、功能说明
-------------------------------------
- 实时视频流显示
- 检测结果展示
- 缺陷尺寸计算
- 样品尺寸显示
- 图片上传检测
- 机械臂状态显示

四、缺陷类型
-------------------------------------
ca_shang  = 擦伤
zhen_kong = 真空
zang_wu   = 脏污
zhe_zhou  = 折皱
good      = 合格

五、参数配置
-------------------------------------
在 video_client_server.py 中修改：

PIXEL_TO_MM = 0.1      # 像素转毫米比例
SAMPLE_WIDTH_MM = 100  # 样品宽度
SAMPLE_HEIGHT_MM = 80  # 样品高度

六、停止服务
-------------------------------------
按 Ctrl+C 停止

七、常见问题
-------------------------------------
Q: 提示权限不足？
A: 执行 chmod +x run.sh

Q: 提示找不到Python？
A: 执行 sudo apt install python3

Q: 提示缺少依赖？
A: 执行 pip3 install flask requests opencv-python numpy
